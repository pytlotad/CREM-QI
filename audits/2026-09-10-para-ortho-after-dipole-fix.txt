321. PIERWSZY FOTON Z n = 2: GDZIE LADUJE ORBITA
     (zlecenie autora: zbadac zastrzezenie "w modelu nie ma dyskretnego
     przejscia 2 -> 1; foton niesie hbar*omega wlasnej orbity, wiec z n = 2
     laduje przy n = sqrt2; odstep Bohra 3/4 B1 daje dopiero
     --bohr-photon-energy, a i wtedy energie moze przyciac warunek momentu
     pedu").  Zastrzezenie bylo prawdziwe tylko w polowie, a przyciecie nie
     "moze" zajsc, tylko zachodzi zawsze.

321a. MECHANIZM (crem_collapse.hpp, sufit energii, domyslny od 228).
     Foton niesie hbar wzdluz d ze skretnoscia h, wiec L' = |L - h hbar d|.
     Orbita o momencie L' ma energie co najmniej -B1/(L'/hbar)^2 (e^2 >= 0),
     co daje sufit E_gamma <= B1 (hbar^2/L'^2 - 1/4) z kola n = 2
     (L = 2 hbar, E = -B1/4).  L' >= 2 hbar: sufit <= 0, losowanie
     odrzucone (redraw).  Przyciety foton zostawia orbite KOLOWA przy
     n = L'/hbar.  Do n = 1 trzeba L' = hbar, tj. d || L i h = +1 --
     zbior miary zero.

321e. WNIOSEK.  W modelu nie ma przejscia 2 -> 1 w zadnym trybie energii
     fotonu.  Ograniczeniem nie jest energia, tylko moment pedu: jeden foton
     zabiera co najwyzej hbar, a z L = 2 hbar orbita n = 1 (L = hbar) jest
     osiagalna tylko przy idealnym ustawieniu.  W QM przejscie 2p -> 1s
     (l = 1 -> 0) zabiera wlasnie hbar i jest dozwolone; w modelu kolo
     n = 2 niesie klasyczne L = 2 hbar, o jeden kwant za duzo -- ta sama
     rozbieznosc L_klas = n hbar wobec l <= n - 1, ktora 303 i 308
     wskazaly przy zamknieciu kanalu E1.  Odstep 3/4 B1 z flagi zostaje
     przyciety srednio do 41 procent.
     Korekta zastrzezenia autora (ktore bylo moim sformulowaniem z poprzedniej
     odpowiedzi): przy hbar*omega n = sqrt2 to tylko polowa przypadkow;
     druga polowa konczy wyzej (do 1,91), kolowo.

LIMITS.
     * Tylko pierwszy foton, tylko start kolowy n = 2 (L = 2 hbar).  Start
       z L = hbar (odpowiednik 2p z l = 1) nie byl badany; tam d || L nie
       jest potrzebne i 2 -> 1 moze byc osiagalne.
     * Przewidywanie nierelatywistyczne; silnik liczy sufit z niezmiennika
       W, roznice ponizej rozdzielczosci 20-27 zdarzen.
     * Mediana Bohra 1,357 wobec przewidywanych 1,47 (dla tego wariantu
       regula nie byla zarejestrowana) -- przy 27 zdarzeniach ~1,5 sd.
     * Pierwsza proba Bohra (budzet 240 s, bohr-240s-cenzura.txt) dala
       zero fotonow: to cenzura (8-11 tys. ps symulacji wobec 17 500 ps
       potrzebnych), nie wynik.
