302a. H1 TRAFIONE tam, gdzie mierzalne: przy J0 >= 0,25 fotony sa, pierwszy
     zawsze na checkpoincie 12 (przewidywane ~10); przy J0 = 0,15 orto jest
     proba (1 odmowa), para przy 0,15 zabita przez zewnetrzny timeout po
     jednym sztywnym checkpoincie.  Przy J0 <= 0,35 z poprawka bylo zero
     prob (301g), bez niej sa -- co potwierdza z drugiej strony przyczyne
     z 301h.

302b. H2 (CZYSTY TEST R301c) TRAFIONE w osmiu przebiegach z osmiu: n po
     pierwszym fotonie lezy nad max(1 - J0, 1/sqrt 3) w kazdym wierszu.
     Pierwsza wersja analizy pokazala "NIE" przy J0 = 0,7, ale detektor
     (skok J_phi > 0,02) przeoczyl tam pierwszy foton; wykrycie po skoku n
     daje 0,7170 >= 0,5774.

302c. MECHANIZM MOCNIEJSZY NIZ GRANICA: PIERWSZY FOTON UKOLOWIA ORBITE, A
     JEGO WYNIK OPISUJE JEDEN PARAMETR.  Po pierwszym fotonie w kazdym
     przebiegu J_phi = n DOKLADNIE (0,8451/0,8451, 0,7968/0,7968, ...):
     ceiling przycina energie tak, ze para lada na granicy kolowej dla
     nowego L.  Wtedy n_po = |L - hbar d|/hbar = sqrt(1 + J0^2 - 2 c J0),
     gdzie c to kosinus kierunku fotonu wzgledem L (z helicznoscia).  Jedno
     ziarno daje we wszystkich przebiegach to samo losowanie kierunku, wiec
     c powinno byc wspolne:
       c z osmiu przebiegow: 0,6966 0,6980 0,6966 0,6973 0,6969 0,6972
                             0,6971 0,6970   -> 0,6971, rozrzut 0,0014,
     i ten jeden parametr odtwarza wszystkie osiem n_po do czterech cyfr
     (0,8450 / 0,7966 / 0,7436 / 0,7170 wobec zmierzonych 0,8451-0,8447 /
     0,7968-0,7965 / 0,7437-0,7435 / 0,7170-0,7171).  Granica z R301c jest
     przypadkiem c = 1 (kierunek optymalny).

302d. KONIEC KASKADY JEST TEN SAM CO PRZY STARCIE KOLOWYM.  Drugi foton
     (checkpoint 62-71) sprowadza pare do n ~ 0,42-0,45 przy J_phi + n < 1,
     czyli zamyka kanal E1 (298a), a dalej jest pelzanie z 296-299, uciete
     budzetem.  t_sym 215-330 ps to wiec znowu czas ucietego pelzania, nie
     czas zycia.  Bez poprawki harmonicznej obszar bliski 1s nie ucieka od
     pelzania -- wpada w nie po dwoch-trzech fotonach; z poprawka (301g-h)
     rozpada sie przez kredyt ksiegowy bez fotonow.  W obu wariantach czas
     zycia w tym obszarze nie jest czysta obserwabla fizyczna.

302e. H3 i H4.  H3: orto przy J0 = 0,10 zapada sie klasycznie w pierwszej
     orbicie (ReachedCutoff, czas 0) -- trafione; para przy 0,10 utknela w
     jednym sztywnym checkpoincie na caly budzet 900 s (w 301g przy 1500 s
     doszla do konca po dwoch), wiec dla para nierozstrzygniete.
     H4: chwile i skutki fotonow sa w para i orto identyczne do czterech
     cyfr; rozni sie tylko liczba odmow pozniej (19/28 przy 0,5, 21/23 przy

     ukolowiajacy orbite przenosi pare daleko od jadra, zanim ta roznica
     zdazy zadzialac.
