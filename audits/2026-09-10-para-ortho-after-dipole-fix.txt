349. REGULA DZIALANIA: FOTON ZABIERA hbar GLOWNEGO DZIALANIA KEPLERA --
     LINIA 2 -> 1 = 5,10212 eV W 100 % (POMIAR 5,10179), LADOWANIE DOKLADNIE
     NA n = 1; Delta l = +1 ZACHOWUJE DZIALANIE RADIALNE I DAJE "2s"
     (pytanie autora o kandydata na poziomy Bohra; zlecenie: "tak").
     Prereg349.txt przed pomiarem.  Osobno p-Ps i o-Ps.

349a. REGULA (przelacznik testowy CREM_ACTION_PHOTON, domyslnie wylaczony).
     Energia Keplera zalezy tylko od J = J_r + L (Delaunay): E = -B (hbar/J)^2,
     omega = dE/dJ.  Foton zabiera hbar z J: E_orb spada o
     integral omega dJ = E(n) - E(n-1) przy KAZDYM e (harmoniczna k: Delta n
     = k, podloga n' = 1); z odrzutem E_gamma = Delta - Delta^2/(2W); sufit
     e^2 >= 0 odrzuca foton zamiast go przycinac; zamkniecie: n <= 1 albo
     L' > max(1, n - 1).  Delta l = -1 przy L >= hbar: Delta J_r = 0.
     Klasyczne E = hbar omega jest granica tej reguly dla malego skoku.
     Walidacja (przelacznik wylaczony) 64/64.

349d. UWAGA AUTORA (po wynikach czastkowych): "to jest wejscie na n = 1, a nie
     na n = 0, wiec kontakt i czas zycia maja prawo sie nie zgadzac".  Slusznie:
     E[T] liczy anihilacje recepta 342 (sigma v [w + (1-w) eps] <n>_orb) z
     klasycznej orbity n = 1, ktora przy L ~ hbar nie dochodzi do zera.  W
     regule dzialania kontakt to J = 0 (L = 0 i J_r = 0) -- stan "n = 0";
     anihilacja bylaby ostatnim krokiem kaskady 1 -> 0, a czas zycia --
     oczekiwaniem na ten krok, nie calka z <n> po orbicie n = 1.  Porownania
     E[T] z 125,14 ps / 142,04 ns z 346-349 nie testuja wiec tego modelu.
     Otwarte: (1) kinematyka -- przy Delta l = -1 krok do n' = 0 wymaga
     L' = |L - hbar| = 0, czyli L = hbar (kolo, J_r = 0); (2) tempo kroku --
     model nie ma go jeszcze, a musi rozdzielic kanaly (pomiar 1135).

349e. WNIOSEK.  Regula dzialania jest kandydatem na poziomy Bohra wyprowa-
     dzonym z geometrii Keplera (E zalezy tylko od J), nie importem: daje
     przerwy E(n) - E(n-1) przy dowolnym mimosrodzie, linie 2 -> 1 w 100 %
     kaskad (5,10212 eV, +0,33 meV od pomiaru, rzad alfa^2), dokladne n = 1
     i podloge bez stanow n < 1.  Z Delta l = +1 przy |L| < hbar (QM: z l = 0
     tylko Delta l = +1) zachowuje J_r i zostawia stany L0 < hbar przy n = 2
     zamkniete -- odpowiednik metastabilnego 2s (E1 2s -> 1s zabronione).
     Dyskretnosc: siec niezmiennicza (calkowite n zostaje calkowite), nie
     atraktor -- start przy niecalkowitym n dalby drabine przesunieta.

LIMITS.
     * Jeden start (n = 2, mikrokanoniczny), 48 par, jedno ziarno.
     * Tempo kaskady nie porownane z pomiarem (czas zycia 2P Ps -- brak
       zrodla pomiarowego w repozytorium).
     * Przy n w (1; 2) skok jest do n' = 1 (Delta J < hbar) -- nieobjete,
       start przy calkowitym n go nie odwiedza.
