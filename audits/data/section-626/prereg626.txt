Prerejestracja audytu 626 (2026-10-24), zapisana przed skryptem.
Polecenie autora: sprawdzic pare dlugosci z 625d (krok orbitalny w punkcie srodkowym reguly B: sin theta_L = hbar/L_m, L_m = l_>; krok spinowy z dlugoscia
reguly Q poczatkowego J: sin theta_J = hbar/((J + 1/2) hbar)) na pozostalych galeziach 6j -- "wzdluz" Delta l i "w bok".

KLASYFIKACJA GALEZI (mu = J - l, rzut spinu na os L; E1: Delta l = +-1, Delta J = 0, +-1; Delta mu = Delta J - Delta l):
  wzdluz  Delta J = Delta l  (Delta mu = 0)         -- droga klasyczna (610), bez kroku;
  w bok   Delta J = 0        (Delta mu = -Delta l)   -- jeden krok: zmiana l przy stalym J (krok orbitalny, theta_L);
  wbrew   Delta J = -Delta l (Delta mu = -2 Delta l) -- dwa kroki: orbitalny, potem spinowy (625), stan posredni mu'' = mu - Delta l.
  Galeziom z |mu'| > S albo J' poza trojkatem (l', S) odpowiada zero (ten sam zakres co w QM).

WARIANTY (spin S = 1/2 wodoru i S = 1 trypletu Ps; QM: P = (2J' + 1){l J S; J' l' 1}^2 / suma po J', 6j wymiernie).
  W1 (jeden efektywny obrot): P(mu -> mu') = |d^S_{mu' mu}(Theta)|^2, 1 - cos Theta = sin theta_L sin theta_J (para 625d); dla wbrew przy S = 1 to z konstrukcji
     postac 625d.
  W2 (kroki 625): w bok P = |d^S_{mu' mu}(theta_L)|^2; wbrew P = |d^S_{mu'' mu}(theta_L) d^S_{mu' mu''}(theta_J)|^2; wzdluz P = 1 - suma pozostalych z tego J
     (unitarnosc: suma galezi z danego J = 1, jak w QM).
  W3 (kontrola, punkt srodkowy pary J, J' jak V3 audytu 625): jak W2, ale sin theta_J = hbar/J_m, J_m = max(J, J') w dlugosciach Borna (sin^2 = 1/J_>^2 przy
     |Delta J| = 1).
  Dla S = 1/2: d^{1/2}_{-+1/2, +-1/2}(theta) = +-sin(theta/2), |d|^2 = sin^2(theta/2); dla S = 1: |d^1_{+-1,0}|^2 = |d^1_{0,+-1}|^2 = sin^2 theta / 2,
  |d^1_{+-1,-+1}|^2 = ((1 - cos theta)/2)^2, |d^1_{0,0}|^2 = cos^2 theta, |d^1_{+-1,+-1}|^2 = ((1 + cos theta)/2)^2.
