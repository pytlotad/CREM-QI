350a. KINEMATYKA.  Krok 1 -> 0 nie jest fotonem E1: fotony anihilacyjne
     (2 gamma / 3 gamma) zabieraja caly J = L + S1 + S2, wiec regula
     Delta l = -1 (L' = |L - hbar|) go nie ogranicza i kazdy stan n = 1 moze
     anihilowac.  Kanal wybiera waga w z konfiguracji spinow (342).

350b. TEMPO.  Twierdzenie Quigga-Rosnera (QM, scisle dla stanow s):
     |psi(0)|^2 = (mu / 2 pi hbar^2) <dV/dr>.  Klasyczna orbita ma
     <k/r^2> = k hbar / (n^3 a^2 L), stad n_QR = (1 / 2 pi a^3 n^3)(hbar / L),
     przy n = 1 rowne |psi_1s(0)|^2 dla L = hbar/2 (Langer).
     Gamma = sigma v [w + (1 - w) eps_OP] n_QR.  Import: tozsamosc QR -- nie
     |psi0|^2 i nie promien rozmycia (wynik od eps niezalezny, w przeciwien-
     stwie do L* z 347).  Analitycznie: A' <L'> = <|L0 - 1|> = 1/2 dokladnie
     (L0 ~ L0 dL0 na [0; 2]) -> tau_p = 124,49 ps / w, tau_o = 138,7 ns;
     C' (L0 >= 1) <L'> = 5/9 -> 138,3 ps, 154 ns.
