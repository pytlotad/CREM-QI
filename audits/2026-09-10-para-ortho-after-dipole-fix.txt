345. SKAD STAN KOLOWY BEZ KONTAKTU: NIE SAMA REGULA ZAMKNIECIA, LECZ ODBICIE
     |L - hbar| PRZY L < hbar I SUFIT LADUJACY NA OKREGU
     (zlecenie autora: "zbadac, dlaczego regula zamkniecia |L/hbar - 1| >= n
     tworzy kolowy stan bez kontaktu, ktorego w QM nie ma").
     Prereg345.txt przed pomiarem.  Osobno p-Ps i o-Ps.  Bez zmian w kodzie.

345a. METODA.  Zespol z 343 (mikrokanoniczny, spiny kwantowane, n = 1),
     rodzina kolowa (12 par) i eliptyczna (28 par), oba kanaly;
     CREM_EMISSION_REACH: kazdy foton -- (n, L/hbar, e^2) przed i po,
     harmoniczna k, czy przyciety sufitem e^2 >= 0.  Rodzina bariery
     nie sledzona.

345b. ANALIZA (przed pomiarem).  Foton Delta l = -1 daje L' = ||L| - hbar|;
     sufit zabrania orbity glebszej niz okrag o L', wiec foton przyciety laduje
     DOKLADNIE na okregu n' = L'/hbar.  Dla okregu zamkniecie |n - 1| >= n
     <=> n <= 1/2.  Przy n = 1 regula zamyka TYLKO L = 0 (stan QM 1s, l = 0).

345c. WYNIK (analysis.txt).
                               p-Ps                    o-Ps
     kolowe: ostatni foton     przyciety 12/12,        przyciety 12/12,
             laduje e^2 = 0    12/12                   12/12
             L0 (start)        0,365 - 0,687           0,365 - 0,687
             n_kon = min(L0, 1 - L0)   do 1,8e-4       do 5,9e-3 (dryf spin-orbita)
     eliptyczne: ostatni foton przyciety 0/28          0/28
             laduje na         n = 1/sqrt(1+2k): 0,577 / 0,447 / 0,378 / 0,333
             L0 (start)        0,23-0,32 lub 0,62-0,92 (tak samo w obu kanalach)
     Kolejnosc zdarzen w rodzinie kolowej:
       1. start n = 1, 0 < L0 < hbar -- przy n = 1 kanal jest OTWARTY dla kazdego L0 > 0;
       2. foton: L1 = hbar - L0 (obieg sie ODWRACA), harmoniczna k zada
          ladowania na n_k = 1/sqrt(1+2k); gdy L1 > n_k sufit przycina ->
          okrag n1 = L1 (22/24 pierwszych fotonow; wyjatek idx 42 p i o, gdzie k = 1
          wyladowal na elipsie n = 0,577 i dopiero nastepny foton zszedl na okrag);
       3. okrag n > 1/2: kolejny foton L = 1 - n < n, znowu przyciety ->
          okrag n = L0.  Okregi "odbijaja sie" L0 <-> 1 - L0, az n <= 1/2.
     Rodzina wyznaczona przez pierwszy foton: kolowa gdy 1 - L0 > 1/sqrt(1+2k)
     (przyciecie), eliptyczna gdy 1 - L0 < 1/sqrt(1+2k) (ladowanie na
     harmonicznej z malym L -> e ~ 0,9).  Regula przyciecia 1 - L0 > 1/sqrt(1+2k)
     trafia 80/80 pierwszych fotonow.  END identyczne z 343/final.txt.

345d. REGULY.
     H345a (L0 w [0,5; 1), n_kon = 1 - L0, pierwszy foton przyciety): NIE --
            L0 w [0,365; 0,687], n_kon = min(L0, 1 - L0) przez odbijanie
            okregow; idx 42 pierwszy foton nieprzyciety.
     H345b (rodzina eliptyczna: pierwszy foton nieprzyciety): NIE dosl. --
            5 par (idx 9, 14, 18, 24, 27; oba kanaly) ma pierwszy przyciety
            na okrag n > 1/2, a nieprzyciety jest OSTATNI (56/56).
     H345c (kanaly identyczne): TAK -- te same rodziny, L0 rozne o <= 0,031 (idx 9, dryf spinow przed 1. fotonem).

345e. WNIOSEK.  Regula zamkniecia sama jest zgodna z QM tam, gdzie QM ma
     stan podstawowy: n = 1, L = 0 jest zamkniety, i to jest stan z kontaktem.
     Stan kolowy bez kontaktu powstaje z trzech elementow modelu, z ktorych
     zaden nie ma odpowiednika w QM:
       (i)  start przy n = 1 z L0 > 0 -- klasyczny zespol nie trafia w l = 0,
            a przy n = 1 kanal pozostaje otwarty dla kazdego L0 > 0;
       (ii) foton Delta l = -1 przy |L| < hbar ODBIJA L do hbar - |L|; w QM
            przejscie E1 z l = 0 jest wylacznie Delta l = +1, a ponizej n = 1
            nie ma poziomow;
       (iii) przyciety foton laduje dokladnie na okregu (e = 0), stad n = L.
     Poziomy n < 1 sa w ogole poza QM; rodzina kolowa (n ~ 0,44) i eliptyczna
     (n = 0,33-0,58) obie leza ponizej 1s.  Kontakt eliptycznej jest
     "przypadkowo" duzy, bo L1 = 1 - L0 jest male.
